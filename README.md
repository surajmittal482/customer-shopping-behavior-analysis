
# Customer Shopping Behavior Analysis

## Project Overview

This project explores retail customer shopping behavior using Python, PostgreSQL, and Power BI. The objective is to analyze purchasing patterns, customer preferences, discount usage, and subscription behavior to support data-driven business decisions.

## Tools & Technologies

- **Python:** Pandas, data cleaning, exploratory data analysis
- **SQL:** PostgreSQL, aggregations, subqueries, CTEs, window functions
- **Power BI:** Interactive dashboards and data visualization

## Dataset

- **Total records:** 3,900
- **Total columns:** 18
- **Key attributes:** Customer demographics, purchase amount, product category, discounts, review ratings, shipping type, and subscription status.

## Project Workflow

### 1. Data Preparation Using Python

- Loaded and explored the customer shopping dataset.
- Checked data types and missing values.
- Handled missing review ratings using category-wise median imputation.
- Created age-group and purchase-frequency features.
- Prepared the dataset for SQL analysis.

### 2. Business Analysis Using PostgreSQL

Wrote SQL queries to investigate 10 business questions:

1. Revenue generated by gender.
2. Customers using discounts while spending above average.
3. Top five products by average review rating.
4. Average purchase amount by shipping type.
5. Spending and revenue by subscription status.
6. Products with the highest discount rates.
7. New, returning, and loyal customer segmentation.
8. Top three most-purchased products within each category.
9. Subscription status among repeat buyers.
10. Revenue contribution by age group.

### 3. Interactive Dashboard Using Power BI

Developed a dashboard to visualize:

- Total customer count
- Average purchase amount
- Average review rating
- Customer subscription distribution
- Revenue and sales by product category
- Revenue and sales by age group

The dashboard includes slicers for subscription status, gender, category, and shipping type to explore customer behavior interactively.

## How to Run the Project

1. Download or clone this repository.
2. Open the Python notebook using Jupyter Notebook or Google Colab.
3. Update the dataset path if necessary and execute the notebook.
4. Load the prepared data into PostgreSQL.
5. Execute the SQL queries in the SQL folder.
6. Open the Power BI dashboard using Power BI Desktop.
